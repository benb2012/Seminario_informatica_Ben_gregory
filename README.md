# Reprodutor Musical

## Descrição
O projeto consiste no desenvolvimento de um reprodutor musical utilizando Python, com uma interface gráfica que permita ao usuário reproduzir e organizar músicas armazenadas localmente em seu computador.

O programa permitirá selecionar arquivos de áudio, visualizar as músicas adicionadas em uma lista de reprodução, selecionar qual música deseja ouvir e utilizar controles básicos de reprodução. Também será possível reorganizar a ordem das músicas, remover arquivos da lista e salvar a organização para que ela permaneça disponível quando o programa for aberto novamente.

A aplicação funcionará localmente, sem depender de serviços de streaming ou conexão com a internet para reproduzir as músicas.

## Funcionalidades
- Adicionar músicas armazenadas no computador.
- Exibir as músicas em uma lista.
- Selecionar e reproduzir uma música.
- Pausar e continuar a reprodução.
- Parar a reprodução.
- Avançar e retornar entre músicas.
- Reorganizar a ordem das músicas.
- Remover músicas da lista.
- Salvar e carregar a lista de reprodução.

## Tecnologias
- **Python:** linguagem utilizada para desenvolver a aplicação.
- **Tkinter:** criação da interface gráfica.
- **VLC / python-vlc:** reprodução dos arquivos de mídia.
- **JSON:** armazenamento da lista de reprodução.

## Objetivo
Desenvolver uma aplicação funcional, simples e intuitiva, aplicando conceitos de programação, manipulação de arquivos, interfaces gráficas e integração entre bibliotecas.

## Funcionamento
O usuário poderá adicionar arquivos de mídia presentes em seu computador, organizá-los em uma lista e controlar sua reprodução por meio da interface gráfica. A lista de reprodução poderá ser armazenada localmente para preservar sua organização entre diferentes execuções do programa.
